# cadence

a little tool for building playlists based on song(s) tempo. 

thought of this when sorting my spotify queue pre running session. pick a song that feels right for each stretch of the run — easy warmup, building, all out, cooldown — and it fills the gaps with tracks at a similar bpm.

wip

BPM data provided by [GetSongBPM](https://getsongbpm.com).
